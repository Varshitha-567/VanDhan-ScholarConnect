# 🌿 VanDhan ScholarConnect

### A Digital Scholarship Platform for Tribal Students

VanDhan ScholarConnect is a web-based scholarship portal prototype designed to help tribal students discover scholarship opportunities, explore eligibility information, and navigate the scholarship application process through a centralized interface.

The project aims to make scholarship information more accessible and simplify the student application journey.

## 📖 Overview

Students can face difficulties discovering relevant scholarships, understanding eligibility criteria, and keeping track of application requirements. VanDhan ScholarConnect explores how a unified digital portal can make this process easier.

The prototype demonstrates a student-oriented interface for browsing scholarship information, navigating application pages, and exploring a digital scholarship application workflow.

## 🎯 Problem Statement

Build a unified scholarship portal that improves access to scholarship information for tribal students and demonstrates a simpler, more organized application experience.

## 💡 Objectives

- Centralize scholarship information in one interface.
- Make scholarship discovery easier for students.
- Present scholarship details and eligibility information clearly.
- Demonstrate a structured application workflow.
- Provide a foundation for a future full-stack scholarship management system.

## ✨ Features

- **Scholarship Discovery:** Explore available scholarship information.
- **Student Dashboard:** Navigate student-facing portal pages.
- **Application Workflow:** Explore scholarship application screens.
- **Responsive Interface:** Access the interface across supported screen sizes.
- **Demo Authentication:** Demonstrate the sign-in experience using browser-side storage.
- **Deployed Prototype:** Access the application through the hosted demo.

> Note: Features and data availability depend on the current prototype implementation. Demo authentication is not production-grade authentication.

## 🔄 Application Workflow

1. Open the VanDhan ScholarConnect portal.
2. Navigate to the student-facing pages.
3. Explore scholarship listings and available details.
4. Navigate through the application workflow.
5. Review the prototype's dashboard and interface.

The current implementation is a frontend prototype. Actual application submission, government verification, and scholarship disbursement must not be assumed to be operational.

## 🚀 Getting Started

### Prerequisites

- Node.js compatible with the project's Next.js version
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Varshitha-567/VanDhan-ScholarConnect.git
```

### 2. Enter the project directory

```bash
cd VanDhan-ScholarConnect
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Visit:

```text
http://localhost:3000
```

### 6. Create a production build

```bash
npm run build
```

Resolve any build errors before deploying new changes.
